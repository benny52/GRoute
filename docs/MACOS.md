# HyRoute для macOS (тестовая версия)

HyRoute для Mac — та же программа, что и для Windows: те же серверы
(Hysteria 2 и VLESS), подписки, правила по программам и сайтам, группы
серверов, локальные прокси, статистика. Окно то же самое. Перехват трафика
устроен по-другому: вместо драйвера WinDivert — встроенный в macOS
виртуальный интерфейс utun.

Версия тестовая: про всё, что работает не так, как на Windows, пишите в
issues (что делали, что ожидали, что получилось, и диагностику из
«Настроек» → «Система» → «Скопировать диагностику»).

## Установка

1. Скачайте `HyRoute-<версия>-macos-universal.zip` со страницы релизов. Один
   архив подходит и для Apple Silicon (M1–M4), и для Intel.
2. Распакуйте его и перетащите `HyRoute.app` в «Программы».
3. Программа не подписана сертификатом Apple, поэтому при первом запуске
   macOS её не откроет. Разрешите запуск один раз:
   - macOS 15 и новее: попробуйте открыть HyRoute, затем «Системные
     настройки» → «Конфиденциальность и безопасность» → внизу «HyRoute
     заблокировано…» → «Всё равно открыть»;
   - macOS 13–14: щёлкните HyRoute правой кнопкой → «Открыть» → «Открыть»;
   - или в Терминале: `xattr -dr com.apple.quarantine /Applications/HyRoute.app`.
4. При первом запуске HyRoute попросит пароль администратора. Он нужен,
   чтобы установить службу HyRoute: она работает с правами root и
   направляет трафик Mac. Пароль спрашивается и после обновления HyRoute
   (новая версия ставит свою службу).

Управлять HyRoute могут только администраторы этого Mac.

## Как это работает

- **Служба** (`/Library/Application Support/HyRoute/bin/HyRoute --daemon`)
  запускается вместе с Mac через launchd. В ней работают подключение,
  правила, Hysteria и Xray. Закрытие окна ничего не отключает.
- **Окно** (`HyRoute.app`) — только интерфейс. Откройте его, чтобы
  подключиться, отключиться или поменять настройки.
- При подключении HyRoute создаёт интерфейс `utun` с адресом `198.18.0.1`
  и маршруты `0.0.0.0/1` и `128.0.0.0/1` через него (для IPv6 — `::/1` и
  `8000::/1`, если у Mac есть IPv6). Локальная сеть идёт мимо, как и
  раньше. Адреса серверов получают отдельные маршруты через роутер.
- Весь TCP проходит через relay HyRoute: прямые соединения он открывает
  сам с физического интерфейса (Wi-Fi или Ethernet), туннельные — через
  Hysteria или Xray. UDP прямых программ HyRoute отправляет со своего
  сокета на физическом интерфейсе.
- Если служба упадёт, macOS удалит `utun` вместе с маршрутами, и трафик
  пойдёт напрямую.

## Правила по программам

В правилах программа указывается по имени исполняемого файла, как его
видит macOS: `Safari`, `Telegram`, `Discord`, `curl` и так далее (без
`.app`). Кнопка «Обзор» в правиле принимает `.app` и сама находит имя
файла внутри него. Подсказки «Запущенные программы» тоже работают.

Системные службы macOS часто ходят в сеть за программы (например,
`nsurlsessiond` скачивает для App Store). Такие соединения HyRoute
относит к программе, для которой они сделаны, если macOS это сообщает.

## Чего пока нет

- **Kill switch**: на Mac его пока нет; при отключении и при сбое трафик
  идёт напрямую.
- **Значок в строке меню**: управление только из окна.
- **Автообновление**: новую версию скачайте и поставьте поверх старой; при
  запуске она обновит службу.
- **hyroutectl и расширение браузера** — только на Windows.
- **ping** (ICMP) к адресам в интернете при подключении не проходит; TCP и
  UDP работают.
- **DNS-политики** работают, только если DNS-сервер Mac не в локальной
  сети или запросы к нему идут через `utun`; это ещё проверяется.

## Удаление

```sh
sudo "/Library/Application Support/HyRoute/bin/HyRoute" --uninstall-service
```

Затем удалите `HyRoute.app`. Настройки и серверы остаются в
`/var/root/Library/Application Support/HyRoute` (папка root); чтобы удалить
и их: `sudo rm -rf "/var/root/Library/Application Support/HyRoute"`.

## Журналы

- журнал службы при запуске: `/Library/Logs/HyRoute-service.log`;
- журналы HyRoute: `/var/root/Library/Application Support/HyRoute/logs`
  (читаются через `sudo`), а проще — в окне, раздел «Журнал».

## Сборка

На Mac с Xcode Command Line Tools и Go: `scripts/build-macos.sh`. Скрипт
собирает универсальный `HyRoute.app` и кладёт архив в `dist/`. Hysteria и
Xray он скачивает по ссылкам из `build/deps.json` (раздел `macos`) и
сверяет SHA-256. Каждая сборка в CI (задача `macos`) выкладывает такой
архив в артефакты запуска.
