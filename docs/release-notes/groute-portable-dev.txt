GRoute Portable для Windows x64 · пробная сборка 12 ноября 2026 года

В «Правилах» групповое изменение показывает итоговую цепочку сразу. Можно задать общие назначения, сделать исключения для отдельных правил и сохранить изменения вместе. В мастере выбранную цепочку можно назначить всем VPN-разделам.

Удаление сервера показывает затронутые назначения во всех профилях. После подтверждения правила с таким приоритетным сервером наследуют основной, а из запасных удаляется только этот сервер. Если удалён текущий основной, выберите новый на главной.

Карточка основного сервера показывает состояние его туннеля и счётчики трафика. В окне проверки сразу виден движок выбранного профиля. В подписках можно раскрыть отчёт последней загрузки с протоколами, дублями, пропусками и предупреждениями.

Для проверки распакуйте ZIP в отдельную папку. Сначала завершите предыдущий GRoute Portable через «Выход» в трее, иначе откроется уже запущенный экземпляр. Настройки и пользовательские данные WebView2 хранятся в Data рядом с GRoute.exe.
