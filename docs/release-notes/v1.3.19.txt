HyRoute 1.3.19

- Спящие серверы для локальных прокси. Сервер, который нужен только прокси (например, с «Прокси для серверов» у подписки), больше не работает постоянно: он запускается при первом соединении через свой прокси (оно ждёт 1–3 секунды) и засыпает через 10 минут без соединений. Простаивающие прокси больше не тратят трафик подписки и память; на странице «Прокси» у них написано «сервер спит».
- Серверы VLESS проверяются экономнее: проверка раз в минуту пропускается, если через сервер за эту минуту уже пришли ответы, и спрашивает сначала один адрес, а второй — только если первый не ответил.
