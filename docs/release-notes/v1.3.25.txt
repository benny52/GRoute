HyRoute 1.3.25

- Безопасность: исправлены уязвимости в версиях для Windows и macOS, в разборе ссылок VLESS и в панели HyRoute Server. Подробности будут опубликованы после выхода этой версии. Обновитесь.
- Windows: пока HyRoute запущен не из Program Files, его файл и папки над ним нельзя переименовать или удалить. Программа обновления перед запуском новой версии сверяет её файл с манифестом. Мьютекс обновления может занять только процесс администратора: чужая программа больше не блокирует обновления.
- Обход DPI: правила «Обход DPI: …» берут сайты сервисов вместе с поддоменами (раньше «через VPN» и обход доставались только самому youtube.com, а www.youtube.com и видеосерверы шли по остальным правилам). «Как в ваших правилах» выбирается, только если ваши правила ведут через VPN весь сервис; голос Discord в этом случае идёт через основной сервер. Если сервер, выбранный для «через VPN», удалён, сервис идёт через основной.
- Обход DPI: самопроверка не запускает второй подбор сразу после вашего и не подбирает без интернета; исправлена редкая ошибка, из-за которой HyRoute мог завершиться во время подбора.
- macOS: IPv6, появившийся после подключения (другая сеть, пробуждение), теперь идёт через VPN по правилам, а не напрямую. Включение kill switch больше не обрывает уже открытые соединения, в том числе локальные.
- «Прокси для серверов» подписки: смена доступа из сети, логина или пароля применяется сразу ко всем уже созданным прокси. Резервная копия сохраняет эту настройку: восстановленные прокси подписки больше не пропадают.
- Импорт правил: строка программы и строки сайтов из Clash и «Списка» становятся разными правилами; правило sing-box, сайты которого не распознаны, и правило Xray с незнакомым условием пропускаются с предупреждением, а не становятся шире (раньше такие правила могли пустить трафик напрямую).
- Резервные копии: «Группы: Заменить» ждёт, пока восстановятся файлы, которые на них ссылаются; план предупреждает о правиле из копии, которое отправляет весь трафик напрямую; «Вернуть как было» с нечитаемым settings.json останавливает подключение, а не пускает всё напрямую; после прерванного восстановления новое возможно только после «Вернуть как было».
- Подписки: не больше 3000 серверов из одной подписки, обновление большой подписки больше не подвешивает окно; заголовки устройства не уходят чужому сайту при перенаправлении.
- «Скрыть данные»: ссылки любых схем (hysteria2://, vless://) скрываются в журналах и на экране; скрыты пароль «Прокси для серверов», вставленные ссылки и конфиги, свои сайты обхода, имена прокси и правил, путь, Host и имя сертификата VLESS.
- Ссылки hysteria2 с незакодированными «/», «?» или «#» в пароле читаются правильно.
- DNS: устройство или программа больше не могут вывести DNS через VPN из строя специально составленными именами; кэш DNS ограничен 50 000 записей.
- Серверам VLESS даётся 45 секунд на подключение через спящий прокси и при проверке группы, как в «Проверить».
- Настройки: сохранение любой настройки больше не включает и не выключает расширение для браузера.
- Панель HyRoute Server: при смене адреса или порта сервера с входом по паролю пароль нужно ввести заново; выход каскада защищён от отката, правки в редакторе и повторного развёртывания; проверка ACL с тысячами правил больше не занимает процессор на минуты; HSTS при собственном TLS.
- Мелкие исправления: путь к CA — только локальный файл; журнал движка не перечисляет адреса отклонённых соединений и берёт в кавычки значения с управляющими символами; профили правил больше 16 МБ не сохраняются; база правил с категорией больше 128 МБ отвергается.
