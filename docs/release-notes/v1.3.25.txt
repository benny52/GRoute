HyRoute 1.3.25

- Безопасность, ссылки и подписки VLESS: настройки extra транспорта xhttp передавались в Xray целиком, а Xray работает с правами администратора (на macOS — root). Специально составленная ссылка или подписка могла заставить его записать или прочитать любой файл на компьютере. Теперь из extra берутся только настройки соединения, остальное отбрасывается с предупреждением. Это касается и уже сохранённых серверов, и резервных копий.
- Безопасность, Windows: HyRoute, запущенный не из Program Files, несколько раз заново запускает свой файл с правами администратора (окно, «Перенести в Program Files», обновление). Программа без прав администратора могла подменить этот файл между запусками и так получить права администратора. Теперь, пока HyRoute работает, его файл и папки над ним нельзя переименовать или удалить, а программа обновления сверяет новую версию с манифестом перед запуском.
- Безопасность, Windows: окно HyRoute с правами администратора получало переменные среды пользователя WEBVIEW2_*. Они задают, откуда WebView2 загружает свой код и с какими параметрами запускается, например с портом удалённой отладки. Теперь эти переменные окну не передаются.
- Безопасность, Windows: любая программа могла создать мьютекс обновления HyRoute и этим навсегда заблокировать установку обновлений. Теперь учитывается только мьютекс, созданный процессом администратора.
- Безопасность, macOS: служба с правами root сама записывала и читала файлы по пути, полученному из окна (сохранение журнала, резервные копии). Программа пользователя могла так записать или прочитать любой файл системы. Теперь эти файлы записываются и читаются с правами пользователя, который их выбрал.
- Безопасность, панель HyRoute Server: при смене адреса или SSH-порта сервера сохранённый пароль уходил на новый адрес. Теперь его нужно ввести заново. В редакторе конфигурации скрытый пароль исходящего подключения (SOCKS5, HTTP) больше не подставляется, если адрес подключения изменился: раньше Hysteria отправила бы его на новый адрес. Панель с собственным TLS отдаёт заголовок HSTS.
- Безопасность, подписки: заголовки устройства (X-Hwid, X-Device-*) больше не уходят другому сайту, если панель подписки перенаправляет запрос.
- Обход DPI: правила «Обход DPI: …» берут сайты сервисов вместе с поддоменами. Раньше «через VPN» и обход доставались только самому youtube.com, а www.youtube.com и видеосерверы шли по остальным правилам. «Как в ваших правилах» выбирается, только если ваши правила ведут через VPN весь сервис; голос Discord в этом случае идёт через основной сервер. Если сервер, выбранный для «через VPN», удалён, сервис идёт через основной.
- Обход DPI: самопроверка не запускает второй подбор сразу после вашего и не подбирает без интернета. Исправлена редкая ошибка, из-за которой HyRoute мог завершиться во время подбора.
- macOS: IPv6, появившийся после подключения (другая сеть, пробуждение), теперь идёт через VPN по правилам, а не напрямую. Включение kill switch больше не обрывает уже открытые соединения, в том числе локальные.
- «Прокси для серверов» подписки: смена доступа из сети, логина или пароля сразу применяется ко всем уже созданным прокси. Резервная копия сохраняет эту настройку, и восстановленные прокси подписки больше не пропадают.
- Импорт правил: строка программы и строки сайтов из Clash и «Списка» становятся разными правилами. Правило sing-box с нераспознанными сайтами и правило Xray с незнакомым условием пропускаются с предупреждением, а не становятся шире: раньше такие правила могли пустить трафик напрямую.
- Резервные копии: «Группы: Заменить» ждёт, пока восстановятся файлы, которые ссылаются на группы. План предупреждает о правиле из копии, которое отправляет весь трафик напрямую. «Вернуть как было» с нечитаемым settings.json останавливает подключение, а не пускает всё напрямую. После прерванного восстановления новое возможно только после «Вернуть как было».
- Подписки: из одной подписки берётся не больше 3000 серверов, и обновление большой подписки больше не подвешивает окно.
- «Скрыть данные»: ссылки любых схем (hysteria2://, vless://) скрываются в журналах и на экране. Также скрыты пароль «Прокси для серверов», вставленные ссылки и конфиги, свои сайты обхода, имена прокси и правил, путь, Host и имя сертификата VLESS.
- Ссылки hysteria2 с незакодированными «/», «?» или «#» в пароле читаются правильно.
- DNS: устройство или программа больше не могут вывести DNS через VPN из строя специально составленными именами. Кэш DNS ограничен 50 000 записей.
- Серверам VLESS даётся 45 секунд на подключение через спящий прокси и при проверке группы, как в «Проверить».
- Настройки: сохранение любой настройки больше не включает и не выключает расширение для браузера.
- Панель HyRoute Server: выход каскада защищён от отката, правки в редакторе и повторного развёртывания. Проверка ACL с тысячами правил больше не занимает процессор на минуты.
- Мелкие исправления: путь к CA — только локальный файл. Журнал движка не перечисляет адреса отклонённых соединений и берёт в кавычки значения с управляющими символами. Профили правил больше 16 МБ не сохраняются. База правил с категорией больше 128 МБ отвергается.
