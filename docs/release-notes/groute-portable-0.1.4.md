# GRoute 0.1.4 для Windows

- В одном ZIP доступны портативный запуск и установка с главной страницы. Подписки, серверы и правила переносятся при первой установке.
- Обход DPI можно включить отдельно в обоих режимах. При первом включении GRoute получает и проверяет компонент zapret2.
- В настройках доступно расширение для Chromium. Папка расширения и хост GRoute остаются доступны браузеру после установки программы.
