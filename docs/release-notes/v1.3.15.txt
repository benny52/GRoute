HyRoute 1.3.15

- Mac: правила для программ с именем Windows (Discord.exe, Telegram.exe — из готовых шаблонов, пошаговой настройки правил или перенесённые с Windows) теперь срабатывают и для программ Mac, у которых нет .exe. Новые правила из шаблонов на Mac пишут имя сразу без .exe.
- Mac: шаблон и шаг «Телеметрия Windows» больше не предлагаются.
- Mac: редактор правила показывает программы по-маковски: без .exe, а примеры — с путями Mac (/Applications/Steam.app/*). Введённое имя («discord») больше не дополняется .exe.
