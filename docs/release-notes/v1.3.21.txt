HyRoute 1.3.21

- Обход DPI без VPN (Windows): новая страница «Обход DPI». Отметьте YouTube, Discord и/или свои сайты — они откроются напрямую, через zapret2, не тратя трафик подписки. «Подобрать автоматически» проверяет, что блокируется у вашего провайдера, находит работающий метод и запоминает его для каждой сети; без подбора zapret2 перебирает методы сам. zapret2 скачивается с GitHub при первом включении и проверяется по контрольным суммам. HyRoute держит правила «Обход DPI: …» наверху профиля правил, чтобы эти сервисы шли напрямую, а не через VPN.
