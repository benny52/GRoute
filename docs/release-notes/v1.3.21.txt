HyRoute 1.3.21

- Обход DPI без VPN (Windows): новая страница «Обход DPI». Отметьте YouTube, Discord и/или свои сайты — они откроются напрямую, через zapret2, не тратя трафик подписки. «Подобрать автоматически» выясняет, как провайдер блокирует каждый сервис, пробует все методы сразу (около полуминуты, обход при этом не выключается) и запоминает для каждой сети самый быстрый и запасные; если метод перестал помогать, zapret2 сам переходит на следующий. Если блокировку обходом не открыть (блок по адресу, подмена DNS), HyRoute предложит пустить сервис через VPN одной кнопкой. zapret2 скачивается с GitHub при первом включении и проверяется по контрольным суммам. HyRoute держит правила «Обход DPI: …» наверху профиля правил, чтобы эти сервисы шли напрямую, а не через VPN.
