# GRoute Portable, сборка №2

В «Настройки → Обновления ядер» можно проверить Hysteria, Xray и AmneziaWG и установить доступное обновление. Для возврата к предыдущей версии откройте ту же карточку. При запуске с обычными правами GRoute предложит перезапуск от имени администратора.

Для AmneziaWG настройки показывают версию `groute-awg.exe` и отдельно версию библиотеки Amnezia. Совместимые сборки движка берутся из выпусков `benny52/GRoute`.

Номер сборки теперь виден в настройках и в свойствах `GRoute.exe`. Версия этого файла в Windows — `0.1.0.2`.
