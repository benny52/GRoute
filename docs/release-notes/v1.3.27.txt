HyRoute 1.3.27

- Обход DPI: откатана оптимизация 1.3.26, которая могла тормозить видео YouTube и другие закачки. Она пропускала через zapret2 только часть входящих пакетов, и пакеты могли приходить не по порядку. Теперь при автоматическом выборе метода входящие пакеты снова идут через zapret2 все и по порядку, как в 1.3.25; экономия для QUIC осталась.
- Обход DPI: видео YouTube, которые долго грузились. Страница открывалась, а серверы, с которых идёт видео, — нет, и обход этого не замечал. Теперь неудачи на серверах видео считаются отдельно от страницы, и метод для них меняется сам. Подбор и самопроверка проверяют ещё и серверы видео, к которым недавно обращался браузер (их адреса нигде не сохраняются).
- Обход DPI: новый метод «Разрез с перекрытием под google.com, IP ID 0» — тот, которым zapret-discord-youtube (Flowseal) открывает YouTube. Подбор пробует его вместе с остальными.
- Telegram без VPN: запасной путь через Cloudflare, как в новых версиях tg-ws-proxy. Когда провайдер блокирует адрес WebSocket Telegram, соединения идут через домены на Cloudflare, которые держит автор tg-ws-proxy, — во все дата-центры Telegram, без VPN. Список доменов HyRoute берёт свежий при запуске и раз в час. Переписку Cloudflare не видит (она зашифрована Telegram), но видит, что вы пользуетесь Telegram: путь можно выключить переключателем «Запасной путь через Cloudflare».
- Если обход DPI работает для Discord или своих сайтов, HyRoute сам пропускает через него и домены Cloudflare (провайдеры режут Cloudflare после нескольких килобайт), и Cloudflare идёт раньше VPN. Без обхода DPI он идёт после VPN — вместо прямого соединения.
- Telegram без VPN: можно вписать свой Cloudflare Worker (режим «Для опытных») — свой бесплатный посредник вместо чужих доменов. Инструкция — в справке.
- Telegram без VPN: если фото и видео одного дата-центра не приходят через WebSocket (так бывает на аккаунтах без Premium), HyRoute замечает это сам и на час пускает их другим путём.
- Самопроверка Telegram проверяет и путь через Cloudflare; на странице видно, отвечает ли он и сколько соединений шло через него.
