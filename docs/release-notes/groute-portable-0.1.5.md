# GRoute 0.1.5 для Windows

- В «Обходе DPI» можно выбрать для YouTube автоматический подбор, а для Discord зафиксировать свою стратегию. Полный список открывается в карточке сервиса в обоих режимах интерфейса. Подробности по доменам и видеосерверам раскрываются по нажатию.
- В «Настройках» → «Расширение для браузера» можно сразу выбрать браузер и открыть его страницу расширений. При первом подключении GRoute готовит папку расширения. Режим разработчика включается в самом браузере.
