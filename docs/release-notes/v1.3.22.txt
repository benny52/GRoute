HyRoute 1.3.22

- Повторное «Установить», пока программа обновления ещё ждёт, когда закроется HyRoute, больше не выдаёт «The process cannot access the file because it is being used by another process». HyRoute объясняет, что обновление уже запущено и установится, как только вы выйдете из HyRoute (значок в трее → «Выход»), и не запускает вторую программу обновления.
- Обход DPI: в список Discord добавлены адрес, куда Discord загружает вложения (отправка картинок и видео теперь тоже идёт через обход), и ещё несколько доменов Discord.
