# GRoute 0.1.6 для Windows

- В заголовке окна, боковом меню, мастере, трее и свойствах EXE программа называется GRoute. При запуске из распакованного ZIP настройки и профиль WebView2 хранятся в папке `Data` рядом с программой.
- В «Правилах» встроенный маршрут Telegram отображается как «Обход DPI · Telegram». Подсказка поясняет назначение WebSocket-моста и локального прокси, а также показывает настроенные запасные серверы.
- Кнопка «Открыть страницу расширений» в настройках и мастере проверяет переход на страницу выбранного браузера. Если подтвердить переход не удалось, кнопка «Скопировать адрес» помогает открыть её вручную. Кнопка «Показать папку» открывает расположение расширения в Проводнике.
- В сборку входят изменения 0.1.5: независимый выбор стратегий DPI для каждого сервиса, список встроенных и найденных генератором вариантов, раскрываемые сведения по доменам и выбор браузера при первом подключении расширения.
