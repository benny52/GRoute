## ADDED Requirements

### Requirement: Прямой маршрут BitTorrent

GRoute SHALL предлагать «Торренты — напрямую» в мастере и шаблонах Windows с сохранением порядка применения правил.

#### Scenario: Протокол в обоих режимах

- **WHEN** первым применимым правилом для нового соединения в режиме «Весь трафик» или «Только выбранное» является BitTorrent
- **THEN** открытое приветствие TCP и начальный пакет µTP получают DIRECT
- **AND** остальные соединения проверяются по обычным правилам.

#### Scenario: Дополнительная программа

- **WHEN** пользователь дополнительно выбирает торрент-клиент
- **THEN** прямой маршрут доступен по программе также для зашифрованных раздач
- **AND** распознавание BitTorrent у остальных процессов сохраняется. Повторное применение того же шаблона сохраняет идентификаторы правил.

### Requirement: Действия из текущих соединений

GRoute SHALL открывать меню действий по правой кнопке мыши для наблюдаемых соединений на карте и в таблице.

#### Scenario: Правило для наблюдаемой программы

- **WHEN** пользователь выбирает процесс и действие «Напрямую»
- **THEN** новые соединения программы используют правило активного профиля с учётом приоритета и служебных исключений.

#### Scenario: Редактирование

- **WHEN** пользователь выбирает соединение и команду редактирования
- **THEN** открывается действующее для этого соединения правило активного профиля
- **AND** обновление списка соединений сохраняет выбранное в открытом меню соединение.
