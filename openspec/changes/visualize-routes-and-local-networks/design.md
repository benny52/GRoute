## Context

Расчёт для введённого адреса использует текущий или редактируемый профиль. После открытия из «Соединений» у записи может быть другой маршрут из-за смены правил, выбора участника группы или перехода на запасной сервер.

## Decisions

Сохранить снимок выбранной строки до закрытия меню. Строить расчёт по победителю существующей проверки правил и разрешать цепочку запасных тем же методом, что и при маршрутизации. Использовать исход операции для определения наблюдаемого выхода. Неудачная попытка с заполненным ID профиля ещё не подтверждает передачу трафика.

Для вида «Сейчас» сравнивать последовательные снимки счётчиков отдельных потоков, затем группировать изменения по процессу, назначению и выходу. Учитывать закрывшиеся потоки. Адреса доступны в памяти. За пропущенное измерение показывать прочерк.

Подсети мастера хранить в отмеченном правиле выбранного профиля. Без сохранения мастера действуют прежние настройки. В режиме DIRECT пакет остаётся на выбранном Windows интерфейсе. При явной маршрутизации подсети обрабатывать новые соединения по правилам. Проверять ввод до сохранения и сохранять один результат мастера.

## Verification

Браузерная проверка с искусственными записями соединений и правилами. Проверки Go с модельными пакетами и двумя интерфейсами. Проверка доступности настоящих домашнего устройства и рабочего сервера требует среды владельца с LAN и OpenVPN.
