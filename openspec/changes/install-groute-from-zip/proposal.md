## Why

Второй этап пункта 9 ТЗ добавляет установку из ZIP, который пользователь уже настроил. В версии 0.1.3 портативный режим также исключал подготовку zapret2 и расширение браузера.

## What Changes

- Установка с главной в Program Files с сохранением пользовательских профилей и ярлыком в «Пуск».
- Обход DPI и расширение включаются отдельно в обоих режимах.

## Capabilities

### New Capabilities
- `groute-windows-install` — один Windows ZIP для двух режимов запуска.

## Impact

Клиент Windows, Svelte, упаковка расширения Chromium, интеграция zapret2 и руководство пользователя.
