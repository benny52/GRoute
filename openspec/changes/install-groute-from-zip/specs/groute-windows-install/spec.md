## ADDED Requirements

### Requirement: Установка из портативной копии
GRoute SHALL поддерживать распакованный запуск и установку из одного Windows ZIP.

#### Scenario: Установка настроенной копии
- **WHEN** пользователь нажимает «Установить GRoute» и подтверждает повышение прав
- **THEN** GRoute копирует проверенные файлы в Program Files, создаёт ярлык и открывает установленную копию с подписками, серверами, основным назначением и профилями правил текущего пользователя

#### Scenario: Повторная установка
- **WHEN** у пользователя уже есть настройки установленного GRoute
- **THEN** повторная установка сохраняет эти настройки

#### Scenario: Отмена установки
- **WHEN** пользователь отменяет запрос Windows
- **THEN** портативная программа продолжает работу

### Requirement: Дополнительные компоненты
GRoute SHALL предоставлять независимый выбор обхода DPI и расширения в обоих режимах.

#### Scenario: Обход DPI
- **WHEN** пользователь выбирает сервис и включает обход
- **THEN** GRoute запрашивает необходимые права, получает проверенные файлы zapret2 и сообщает результат, включая ошибку защиты при блокировке файла

#### Scenario: Подключение браузера
- **WHEN** пользователь устанавливает расширение в настройках GRoute и загружает предложенную папку в браузере Chromium
- **THEN** расширение соединяется с запущенным GRoute через собственный локальный хост, в том числе после переноса приложения в Program Files

#### Scenario: Независимый выбор стратегий
- **WHEN** пользователь открывает карточки включённых YouTube и Discord в простом режиме
- **THEN** в каждой карточке доступны автоматический режим, все встроенные стратегии и доступные варианты генератора, а наблюдения по отдельным доменам раскрываются по запросу
- **WHEN** YouTube настроен автоматически, а для Discord сохранена ручная стратегия
- **THEN** подбор проверяет YouTube и сохраняет ручное назначение Discord

#### Scenario: Первый запуск страницы расширений
- **WHEN** пользователь выбирает найденный браузер в настройках и нажимает «Открыть страницу расширений»
- **THEN** GRoute подготавливает файлы и связь при необходимости и открывает страницу выбранного браузера, где пользователь может включить режим разработчика и загрузить папку расширения

#### Scenario: Браузер игнорирует внутренний адрес при запуске
- **WHEN** пользователь открывает менеджер расширений в Windows из настроек или из мастера
- **THEN** GRoute выполняет переход через адресную строку выбранного браузера и подтверждает открытие менеджера перед сообщением об успехе
- **WHEN** окно сменилось во время перехода или результат не удалось подтвердить
- **THEN** GRoute предлагает скопировать адрес для выбранного браузера

#### Scenario: Встроенный маршрут Telegram
- **WHEN** правило использует встроенный WebSocket-мост Telegram
- **THEN** список правил показывает «Обход DPI · Telegram», объясняет роль прокси и называет настроенный запасной маршрут
- **WHEN** пользовательское правило с тем же названием указывает на удалённый сервер
- **THEN** у него остаётся предупреждение об удалённом сервере
