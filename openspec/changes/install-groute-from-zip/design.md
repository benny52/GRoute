# Два режима одного EXE

В распакованной копии профиль лежит рядом с программой. При запуске из целевой папки Program Files тот же EXE открывает пользовательский каталог GRoute в AppData. Оба режима используют общий экземпляр GRoute и собственные компоненты, отдельные от HyRoute.

При установке с обычными правами повышенный дочерний процесс проверяет файлы по SHA-256 из EXE и размещает их в Program Files. Исходный процесс копирует профиль своей учётной записи. Настройки и снимки подписок сохраняют исходные байты с защитой DPAPI. Готовый каталог данных публикуется целиком, существующий профиль сохраняется. При сбое исходные файлы остаются доступны.

Расширение Chromium использует отдельный идентификатор, хост и канал GRoute. Постоянный путь в LocalAppData позволяет браузеру использовать расширение после удаления распакованной копии. Для обхода DPI используется закреплённый выпуск zapret2 с проверкой файлов перед запуском.
