На Windows x64 `go test -tags integration ./internal/session -run TestAmneziaWGPeerFailover -count=1 -v` проверяет тестовые узлы amneziawg-go v0.2.19 (сервер 2.0) и v3.1.20260828 (сервер 3.1). В обоих порядках TCP и UDP получили метку сначала приоритетного, затем запасного узла при том же адресе назначения. Использованы временные ключи и сокеты loopback. Проверку импорта через контроллер и сохранения выполняет `go test ./internal/app -run TestAWG -count=1`.

В этом окружении отдельные прежние сетевые тесты локального прокси завершаются по тайм-ауту. Одиночные первые UDP-пакеты терялись и в самостоятельной проверке двух сокетов Windows. Сквозной тест повторяет UDP-запрос с меткой проверяемого этапа. Проверка `-race` требует поддерживаемого компилятора C.
