## Why

Пользователь хочет использовать в правилах GRoute два типа клиентских профилей AmneziaWG из 3x-ui, включая запасной выход при отказе приоритетного.

## What Changes

Прототип в dev принимает клиентские файлы и ссылки подписки, сохраняет параметры и ключи, поднимает отдельный локальный SOCKS5 для каждого используемого профиля. Прототип входит в портативную Windows-сборку.

## Capabilities

### New Capabilities
- `amneziawg-outbounds` — импорт и работа серверов AmneziaWG 2.0 и 3.1 через существующую маршрутизацию GRoute.

### Modified Capabilities

## Impact

Изменение расширяет пункт 3 ТЗ. Затронуты импорт, хранение профилей, резервное копирование, список серверов, фабрика туннелей и SOCKS5 UDP ASSOCIATE. Для стенда достаточно процессов пользователя, временных ключей и сетевых стеков в памяти.
