### Результаты проверок 12.11.2026

- В контроллере Go проверены удаление SUB1, замена с неактивным профилем, явные и косвенные ссылки при переносе копии, порядок запасных, устаревшее подтверждение и повторное чтение с диска. Отдельный тест хранилища открывает каталог после искусственного прерывания на каждом из шести файлов и сверяет исходные байты.
- В движке на искусственных пакетах проверены отказ VPN-правила без сервера, смена основного для новых соединений и сохранение явно закреплённого сервера. В контроллере статуса проверены причины запуска для правил, маршрута «Всё остальное», групп и прокси.
- В Edge проверены выбор галочками, отмена и применение, неактивный профиль со вторым запасным, редактор и повторное открытие, мастер, карточка, удаление SUB1 и причины подключения на главной. Стенд использует искусственные ответы Wails. Node отдельно проверяет сохранение при смене основного B → C → B. Проверка `svelte-check` завершилась без ошибок и предупреждений, Vite заново собрал встраиваемый `frontend/dist`. Компиляция Windows-пакета GUI с тегами `desktop,production` прошла проверку через `go test -run '^$'`.
- Полный прогон затронутых Go-пакетов выявил сбои UDP-тестов и проверки Windows-мьютекса обновлятора. Эти же сбои воспроизведены на исходном `main` (`6b1bed6`) на том же компьютере. Go vet и адресные тесты пройдены. Для Go `-race` в среде Windows отсутствует C-компилятор. Фактическое соединение через VPN и запуск упакованного приложения относятся к этапу 3.2.
