## Why

Для подключения через WinDivert обычный экземпляр GRoute Portable требовал вручную выйти и найти исполняемый файл.

## What Changes

Добавить действие перезапуска в карточку подключения и на итоговый шаг мастера. Windows запрашивает согласие через UAC на запуск того же файла. При отмене текущее окно остаётся доступно.

## Capabilities

### New Capabilities
- `portable-startup` — передача управления из обычного экземпляра портативного клиента в повышенный.

## Impact

Основной процесс Windows выбирает путь к своему EXE и передаёт собственный PID. После штатного завершения новый основной процесс продолжает запуск в прежнем каталоге. На странице обхода DPI отображается доступность zapret2 для портативной поставки.
