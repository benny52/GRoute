## ADDED Requirements

### Requirement: Одинаковые серверы из поддерживаемых форматов 3x-ui

GRoute SHALL определять формат по телу ответа и загружать поддерживаемые VLESS и Hysteria 2 из ссылок, Base64, Xray JSON и Clash.

#### Scenario: Обычная подписка с отдельным vpn-профилем
- **WHEN** пользователь проверяет Base64 со ссылками VLESS, `hysteria2://`, `hy2://` и неподдерживаемой конфигурацией
- **THEN** поддерживаемые профили доступны к сохранению, пропуск показан отдельно, а замечания к настройкам принятого профиля объясняют конкретное ограничение

#### Scenario: Xray содержит Hysteria 2 и копии исходящих подключений
- **WHEN** пользователь проверяет 3x-ui JSON с отдельными конфигурациями VLESS и Hysteria 2, а также с теми же подключениями под тегами балансировщика
- **THEN** каждый уникальный поддерживаемый сервер сохраняется один раз, совпадающие копии учитываются как дубли, а иная версия Hysteria пропускается с причиной

#### Scenario: Смена представления подписки при обновлении
- **WHEN** те же серверы возвращаются в другом поддерживаемом формате
- **THEN** после сохранения и открытия данных VPN-правило и упорядоченный резерв указывают на прежние серверы
